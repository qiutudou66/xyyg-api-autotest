## 已知未覆盖维度

接口覆盖 ≠ 测试充分。以下维度当前**没有**系统性覆盖，面试被问到要如实说明：

1. **越权访问**：只测了「未登录返回 401」，没测「A 用户操作 B 用户的资源」（如删除他人动态、修改他人店铺）。
2. **并发极限**：只做了 10 并发抢 5 库存，没有压测 QPS、连接池耗尽、Redis 热点 key。
3. **数据一致性边界**：秒杀做了三方一致（Redis 库存 / MySQL 库存 / 订单数），但没覆盖 MQ 消息丢失、消费重复、消费顺序错乱。
4. **兼容性 / 前端联调**：不涉及。
5. **安全扫描**：SQL 注入、XSS、文件上传绕过（只测了 `.txt`，没测伪装成 `.png` 的可执行文件）未覆盖。
6. **幂等与重试**：除秒杀和关注外，其余写接口没有验证重复提交。
